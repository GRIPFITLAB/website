# Ethereal Tech — App UI Kit

## Overview
A high-fidelity recreation of the Ethereal Tech readiness tracking app. The app is a dark-mode biometric dashboard that displays readiness scores, HRV, sleep, and neural drive metrics in an elite sci-fi aesthetic.

## Screens
1. **Dashboard** — Main readiness score + metric grid
2. **Detail Panel** — Expanded metric breakdown
3. **History** — Trend charts over time
4. **Settings** — Profile and device configuration

## Design Width
375px (mobile-first; scales to tablet/desktop)

## Components
- `AppShell.jsx` — Sidebar nav + top bar layout shell
- `DashboardScreen.jsx` — Primary readiness dashboard
- `MetricCard.jsx` — Individual biometric metric card
- `ScoreRing.jsx` — Circular SVG score display
- `DataPanel.jsx` — Detailed data breakdown panel
